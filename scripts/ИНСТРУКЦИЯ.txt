СОСТАВ ПАПКИ
─────────────────────────────────────────────────────────────────
  generate.py       — основной скрипт
  template.docx     — шаблон документа (не удалять и не переименовывать)
  run.bat           — быстрый запуск двойным кликом (Windows)
  requirements.txt  — список библиотек для установки
  ИНСТРУКЦИЯ.txt    — этот файл

Все файлы должны лежать в одной папке. Перемещать их по отдельности
нельзя — скрипт ищет шаблон рядом с собой.


ШАГ 1 — УСТАНОВИТЬ PYTHON (один раз)
─────────────────────────────────────────────────────────────────
Скачать Python: https://www.python.org/downloads/

  • Нажмите кнопку «Download Python 3.x.x» (последняя стабильная версия).
  • Запустите скачанный установщик.

  ┌─────────────────────────────────────────────────────────────┐
  │  !! ОБЯЗАТЕЛЬНО !!                                          │
  │  На первом экране установщика поставьте галочку             │
  │  «Add Python to PATH» — она снята по умолчанию.             │
  │  Без этой галочки команды python и pip работать не будут.   │
  └─────────────────────────────────────────────────────────────┘

  • Только после этого нажимайте Install Now.
  • После установки нажмите «Close».
  • Закройте командную строку (если была открыта) и откройте новую.

Проверка (в командной строке):
  python --version
  → должно вывести «Python 3.x.x»

Если галочку не поставили и Python уже установлен:
  Найдите скачанный установщик (или скачайте снова), запустите его,
  выберите «Modify» → «Next» → поставьте галочку
  «Add Python to environment variables» → «Install».
  После — закройте и откройте командную строку заново.


ШАГ 2 — УСТАНОВИТЬ БИБЛИОТЕКИ (один раз)
─────────────────────────────────────────────────────────────────
Откройте командную строку (Win + R → cmd → Enter) и выполните:

  pip install openpyxl python-docx num2words

Или, если у вас скачан файл requirements.txt, перейдите в папку
со скриптом и выполните:

  pip install -r requirements.txt

Установка занимает 1–2 минуты, после чего она больше не нужна.


ШАГ 3 — ОТМЕТИТЬ СТРОКИ В EXCEL
─────────────────────────────────────────────────────────────────
Откройте файл расчёта премии (2026_TRADE.xlsx или аналогичный).

На листе «Расчет премии» в столбце «Уведомление» (последний столбец Z)
напишите   Сделать   напротив тех строк, по которым нужно создать
уведомление. Регистр не важен — «сделать», «СДЕЛАТЬ» и «Сделать»
работают одинаково.

Сохраните Excel перед запуском скрипта — скрипт читает сохранённые
значения из ячеек (включая результаты формул).


ШАГ 4 — ЗАПУСТИТЬ СКРИПТ
─────────────────────────────────────────────────────────────────
СПОСОБ А — через run.bat (проще всего):
  Перетащите Excel-файл мышью на файл run.bat.
  Или дважды кликните run.bat, и введите путь к Excel в окне.

СПОСОБ Б — через командную строку:
  python generate.py "Z:\09. Accounting\CONTROLLING - FINANCE\Бонусные соглашения\2026_TRADE.xlsx"

  Путь к файлу можно скопировать из адресной строки Проводника.
  Если в пути есть пробелы — заключите его в кавычки.


ШАГ 5 — ЗАБРАТЬ ДОКУМЕНТЫ
─────────────────────────────────────────────────────────────────
После завершения скрипт создаст папку рядом с Excel-файлом:

  Уведомления_ГГГГ-ММ-ДД\

Внутри — готовые .docx файлы, по одному на каждую отмеченную строку.

Пример имени файла:
  Уведомление о расчете премии RSQ1ALL2026 от 31 марта 2026 года.docx


ЧТО СКРИПТ ДЕЛАЕТ АВТОМАТИЧЕСКИ
─────────────────────────────────────────────────────────────────
  • Дата уведомления — текущая дата (дата запуска).
    Исключение: для клиента «Русский Свет» — последний день периода,
    указанного в столбцах «С»/«По».
  • Название премии — берётся из листа «Наименование премии_легенда»
    по значению в столбце «Комментарий».
  • Реквизиты договора — из листа «Реестр договоров».
  • Суммы (База для начисления и Сумма премии) берутся напрямую из
    соответствующих столбцов Excel. Убедитесь, что файл сохранён
    после последнего пересчёта формул.
  • Фраза «за достигнутый товарооборот» добавляется автоматически,
    если в столбце «Категория» содержит слово «Маркетинг».
  • Столбцы определяются по заголовкам строки 2 — скрипт устойчив
    к добавлению новых вспомогательных столбцов в таблицу.

Если для какого-то клиента нет договора в реестре, скрипт выведет
предупреждение в строке, но документ всё равно создаст.


ВОЗМОЖНЫЕ ОШИБКИ И ЧТО ДЕЛАТЬ
─────────────────────────────────────────────────────────────────
«python не является внутренней или внешней командой»
  → Python не добавлен в PATH. Переустановите Python с галочкой
    «Add Python to PATH».

«ModuleNotFoundError: No module named 'openpyxl'»
  → Библиотеки не установлены. Выполните шаг 2.

«Ошибка: шаблон не найден»
  → Файл template.docx отсутствует или перемещён.
    Верните его в ту же папку, где лежит generate.py.

«Ошибка: файл не найден»
  → Проверьте путь к Excel-файлу. Если в пути есть пробелы или
    кириллица — заключите весь путь в кавычки.

Нули в сумме премии вместо реальных значений
  → Excel-файл был сохранён без пересчёта формул. Откройте файл,
    нажмите Ctrl+Alt+F9 (принудительный пересчёт), сохраните и
    запустите скрипт заново.

Word показывает «На сервере имеется более новая версия этого файла»
  → Папка вывода находится на SharePoint/OneDrive. Скрипт сохранил
    файл корректно, но синхронизация ещё не завершилась.
    Нажмите «Отменить изменения» — Word перезагрузит актуальный файл.
    Чтобы избежать предупреждения в будущем: дождитесь зелёной
    галочки OneDrive в трее (файл синхронизирован) и только потом
    открывайте документ.


ВОПРОСЫ И ИЗМЕНЕНИЯ
─────────────────────────────────────────────────────────────────
Если нужно добавить нового клиента — внесите его в лист
«Реестр договоров» в Excel, скрипт подхватит автоматически.

Если нужно добавить новый тип премии — добавьте строку в лист
«Наименование премии_легенда», скрипт подхватит автоматически.
